# 漫剧上滑助手

<img src="docs/images/app-icon.png" width="112" alt="漫剧上滑助手图标">

Android 本地无障碍辅助工具。在指定应用前台识别广告标记或已适配的直播推广结构，并尝试向上滑动。

当前版本：**0.5.10**（versionCode 29），最低 Android 8.0，目标 Android 15。

0.5.10 在首页无障碍权限卡片下方新增常驻“后台运行设置”卡片，提示允许后台运行、将电池策略设为“无限制”，并提供系统设置入口。广告识别和上滑逻辑保持不变。

## 工作方式

- 默认模式读取独立的可见“广告”标记，识别后尝试上滑。每次手势结束至少等待 1 秒，再完整读取页面；首次未见广告立即暂停手势，连续 3 次完整读取未见广告后结束本轮。
- 红果短剧 `com.phoenix.read` 额外适配一种直播推广结构：同一可见分支内的短剧播放流、推广容器和大面积直播播放器，以及无可见剧集控件。同一窗口两次完整读取、相隔至少 1 秒确认后进入上滑循环。
- 空文字、“领取”“立即领取”只是直播结构的辅助条件，不能单独触发上滑。
- 单轮最多 60 次尝试或累计有效检测 90 秒；切出应用、窗口遮挡、读取不完整和长时间检测中断暂停计时。
- 支持横竖屏、观察模式、自定义提示及实验性的控件学习方案。原提示模式与广告循环的间隔规则不同，详见应用内帮助。

当前适配依赖目标 App 提供的节点，不能保证识别所有广告。系统手势完成不代表已返回剧集；第三方 App 更新可能改变页面结构。正式签名包尚未完成真实广告的手机验收。

## 使用

1. 打开助手并启用无障碍服务。
2. 点击首页“去设置后台运行”，在系统应用信息的电池或耗电管理中允许后台运行，将电池策略设为“无限制 / 不限制”；部分手机还需允许自启动或锁定后台任务。设置名称因手机而异，需手动确认，可能增加耗电。
3. 在“应用”页添加目标 App，选择合适的识别方案。
4. 先用观察模式核对识别，再启用自动上滑，全屏打开目标 App。
5. 漏滑时查看“最近未滑原因”；后台限制需根据自己手机的系统设置调整。

## 构建

需要 JDK 17 或 21、Android SDK（API 35）和 Build Tools。将 SDK 路径配置在本机 `local.properties` 或 `ANDROID_HOME` 中；不要提交本机配置。

```powershell
./gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

macOS/Linux 使用 `./gradlew`。Debug 输出位于 `app/build/outputs/apk/debug/app-debug.apk`。

构建自己的正式包请参阅 [Release 构建](docs/release.md)。公开源码不含官方发布私钥，自行构建须使用自己的签名。
